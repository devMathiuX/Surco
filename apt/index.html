Surco

Repositorio APT para Ubuntu, Debian y derivadas (amd64). Última versión: 1.3.3-1

Instalar (una sola línea)

curl -fsSL https://devmathiux.github.io/Surco/install.sh | sudo sh

Después Surco se actualiza con el resto del sistema: sudo apt update && sudo apt upgrade.

Instalar a mano

sudo install -d -m 0755 /etc/apt/keyrings
sudo curl -fsSL https://devmathiux.github.io/Surco/surco.gpg -o /etc/apt/keyrings/surco.gpg
echo "deb [arch=amd64 signed-by=/etc/apt/keyrings/surco.gpg] https://devmathiux.github.io/Surco stable main" \
  | sudo tee /etc/apt/sources.list.d/surco.list
sudo apt update
sudo apt install surco

Desinstalar

sudo apt remove surco
sudo rm -f /etc/apt/sources.list.d/surco.sources /etc/apt/sources.list.d/surco.list /etc/apt/keyrings/surco.gpg
